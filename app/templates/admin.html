How to Assign Roles

Existing user Go to the Users tab, find the user, change the dropdown from their current role to the new one, and click Save. Takes effect immediately — the user's next page load will reflect the new permissions.
New user Use Invite a New Analyst on the Overview tab. Enter their email, choose a role, generate the link, and send it to them. They set their own password — no SQL required.
